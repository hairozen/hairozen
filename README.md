I’m a data scientist on the founding team at **[Accomplish](https://accomplish.ai/)**, building and evaluating self-learning AI workflows. I’m interested in how agents learn from experience, and what happens when they get stuck.

I co-created **[Boundary-Bench](https://boundarybench.com/)** to study coding agents under production-like restrictions. Previously, I was on the founding team at **[Skyline AI](https://www.skyline.ai/)**, acquired by [JLL](https://jll.com) in 2021.

### What I’m working on

| Work | The question behind it |
| :--- | :--- |
| [Accomplish](https://accomplish.ai/) | Can an agent use what happened on one task to do better on the next? |
| [Boundary-Bench](https://github.com/boundary-bench/boundary-bench) | How do security restrictions change coding-agent success, cost, and failure? |
| Skill evaluations | Does a skill actually help agents? |
| Agent memory & model routing | What should an agent remember, and which model belongs at each step? |

### Small tools I build

I like breaking work into manageable tasks and keeping track of what needs doing.
